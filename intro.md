# Getting started

Hands-on notebooks for **CSI 4124 / SYS 5110** at the University of Ottawa.

**Instructor:** Guillaume St-Onge — [www.gstonge.ca](https://www.gstonge.ca)

Every activity on this site is a Jupyter notebook. If you are completely new to Jupyter notebooks,
first have a look at this tutorial: [Jupyter Notebook 101](https://www.kaggle.com/code/jhoward/jupyter-notebook-101).

There are three ways to run the Jupyter notebooks from this platform.

## 1. Google Colab

Each notebook page has a Colab link. It opens in a few seconds, runs on Google's
machines, and saves your work to your Google Drive. This is the easiest path to use during
a live activity.

The only requirement: you need a Google account.

## 2. JupyterLite — no account needed

If you'd rather not sign in to anything, [open the notebooks in JupyterLite](https://www.gstonge.ca/csi4124-sys5110/lite/tree/index.html).
Python runs **inside your browser tab**. There is no server to log into and nothing
to go down.

Three things to know:

- The first load downloads a chunk of Python (tens of MB). It's cached afterwards.
- **Your work is saved in your browser, not in the cloud.** It survives closing the
  tab, but it's tied to that one browser on that one machine, and clearing your site
  data erases it. Fine for a one-hour activity; do not keep multi-week work here.
- **If a notebook looks out of date, or a link says it cannot find the file**, your
  browser is showing you a cached copy from an earlier visit. Open the page in a
  private window, or clear this site's data in your browser settings, then reload.

## 3. A local Python install

Getting Python running on your own machine is part of what this course expects you to be able to do. Do it in week 1, not the night before something is due. You can download each notebook individually or clone the GitHub repository.

It is recommended to use a virtual python environment to avoid creating issues with your system's Python.
